# Community code of conduct

OpenMettle welcomes people with different backgrounds and levels of technical experience. Help make the project a place where people can ask questions, learn and contribute.

## Expected behavior

Be respectful, assume good intent where reasonable, and give constructive feedback about the work. Explain technical concerns clearly. Respect privacy and other people's time. Acknowledge mistakes and correct them.

## Unacceptable behavior

Harassment, discriminatory language, sexualized attention, threats, intimidation, deliberate disruption and publishing someone else's private information are not acceptable. Criticism of an idea does not justify personal attacks.

## Reporting and response

For abusive GitHub content, use GitHub's **Report content** control where available. To contact the project privately, use a private contact method a repository maintainer has explicitly listed on their GitHub profile. Do not assume a commit email is a support address.

If no private contact is listed, open a minimal issue titled **Private contact requested**, without names, allegations, sensitive details or screenshots. A maintainer should provide a private channel before collecting details. A dedicated project reporting address will be added when one is established.

Maintainers may edit or remove harmful content, close discussions, restrict participation or block users, with a response proportionate to the behavior. Reports should be handled discreetly; do not promise absolute confidentiality where GitHub or legal processes may require disclosure.

This policy applies in project repositories, discussions and other spaces managed by OpenMettle.
