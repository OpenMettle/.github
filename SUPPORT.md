# Getting help

OpenMettle is in early development. Start with the relevant repository README and its stated support status.

Use [Discussions](https://github.com/OpenMettle/.github/discussions) for setup questions, hardware planning and design conversations. File a reproducible problem or a concrete feature proposal in the affected repository. For project-wide documentation issues, use this repository.

Include the repository version or commit, operating system, relevant hardware, expected result, actual result and a small sanitized log excerpt. Describe the command or action that led to the problem. Check logs for secrets, personal content and internal addresses before posting.

Community support is best-effort. There is no commercial support contract or response-time guarantee.

Report vulnerabilities privately using [SECURITY.md](https://github.com/OpenMettle/.github/blob/main/SECURITY.md).
